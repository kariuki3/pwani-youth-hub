Pwani Youth Hub — Group B Project

Project overview
We developed a responsive and interactive website for Pwani Youth Hub, a fictional youth community organisation based in Mombasa, Kenya. The organisation runs skills development, sports and mentorship programmes. We designed the website for young people, parents and community partners who want to learn about the organisation and its activities.

Live website: https://kariuki3.github.io/pwani-youth-hub/
GitHub repository: https://github.com/kariuki3/pwani-youth-hub

Website pages
Our project contains the three pages required by the assignment and an additional Gallery page.
Page	File	Description
Home	index.html	Introduces Pwani Youth Hub and highlights its work.
Programmes	programmes.html	Presents the organisation's skills, sports and mentorship programmes.
Get Involved	get-involved.html	Provides contact information, an interest form and FAQs.
Gallery (additional)	gallery.html	Showcases youth activities through images and captions.


Technologies and features
We used:
- HTML5 for the structure and semantic content.
- CSS3 in the shared css/style.css file for styling and responsive layouts.
- JavaScript in js/script.js for interactive features.
- CSS variables to maintain consistent colours and design values.
- Flexbox for the header and navigation layout.
- CSS Grid for programme cards and other content sections.
- Media queries to adapt the layout to different screen sizes.

Our interactive features include:
1. A mobile navigation menu that opens and closes when the menu button is selected.
2. An FAQ accordion that expands and collapses answers.
3. Interest-form validation and browser feedback.
Form note: The interest form is a front-end demonstration. It validates the entered details and displays feedback in the browser, but it is not connected to a backend service and does not send or store submissions.
